---
title: "Version 0.46: Update button and About page"
date: 2026-11-22
version: "0.46.0"
summary: "Parents now update kidCTL on the children's computers with a button in the web interface and see at a glance which version is running."
---

- **Update button:** If a newer kidCTL version is available for a computer, the device page shows an **Update**
  button. One click starts the update on the child's computer without you having to sign in there. The agent only
  fetches its own kidCTL packages from the signed package source. Each computer has to be brought to 0.46 by hand once;
  after that, the button does it.
- **About:** *Settings → About* shows the running version, the release date and links to the project website, release
  notes, guides and the security contact. The tray app on the child's computer has an **About** entry as well.
- **What's new:** After a server update, the overview shows a short summary of the changes once.
- **Project website:** On phones there is now a menu at the top with all sections.
