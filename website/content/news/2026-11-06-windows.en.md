---
title: "KidCTL for Windows 10 and 11"
date: 2026-11-06
version: "0.32.0"
summary: "Screen time, app control, web filter and game limit now on Windows too – with automatic updates."
---

KidCTL now also runs on Windows 10 (22H2) and Windows 11 (23H2 or later), Home and Pro, on 64-bit PCs. A child can
use Linux and Windows computers side by side; the time is counted together.

Windows gets the same features as Linux: screen time with sign-out and sign-in lock, app control with Start menu and
Store apps, web filter, game limit for Steam and Epic, and the tray app with chat and requests. You install it with
an installer served by your own server; after that the agent updates itself and checks its own signature.

The installer is not code-signed yet, so Windows SmartScreen asks once when you first run it.
