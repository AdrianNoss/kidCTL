---
title: "Version 0.40: Invitations by email"
date: 2026-11-20
version: "0.40.0"
summary: "Operators send invitation codes straight by email – with a link that already fills in the code."
---

If you run KidCTL for several families, you can now send an invitation code by email right away. The email contains
a link that takes the family straight to the sign-up form with the code already filled in. If an invitation gets lost,
"Resend" sends a new code. The address is deleted once the code is redeemed or has expired.

The sign-in pages now also show a link to the operator's own homepage (or to the KidCTL project page).
