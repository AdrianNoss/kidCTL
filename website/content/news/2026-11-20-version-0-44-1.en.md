summary: "Several vulnerabilities found in an internal review are fixed. Please update your server and agents."
---

Version 0.44.1 fixes several vulnerabilities found in an internal security review:

- **Agent:** under certain circumstances, a child without admin rights could pause rule enforcement or send a very
  large number of messages to the parents. The agent now also starts if one of its saved files is damaged.
- **Server:** the limit on failed authenticator codes now also holds under many simultaneous requests, pairing codes
  can only be redeemed once, and invoices are protected against duplicate actions.
- **Operation:** the new setting `TRUSTED_PROXIES` defines from which reverse proxy the server accepts the client
  address. If you run other containers in Traefik's network, set it to the address of the Traefik container (see the
  "Server" docs).

Please update the server (rebuild the image and restart) and the agents on the children's computers to 0.44.1.
Details are in the [security advisory](ADVISORY-LINK).
