---
title: "Version 0.44.1: Sicherheitsupdate für Agent und Server"
date: 2026-11-20
version: "0.44.1"
summary: "Mehrere Schwachstellen aus einer internen Prüfung sind behoben. Bitte Server und Agenten aktualisieren."
---

Version 0.44.1 behebt mehrere Schwachstellen, die eine interne Sicherheitsprüfung gefunden hat:

- **Agent:** Ein Kind ohne Admin-Rechte konnte unter bestimmten Umständen die Durchsetzung der Regeln anhalten oder
  sehr viele Nachrichten an die Eltern schicken. Außerdem startet der Agent jetzt auch dann, wenn eine seiner
  gespeicherten Dateien beschädigt ist.
- **Server:** Die Begrenzung der Fehlversuche beim Authenticator-Code greift jetzt auch bei vielen gleichzeitigen
  Anfragen, Kopplungscodes lassen sich nur einmal einlösen, und Rechnungen sind gegen doppelte Aktionen geschützt.
- **Betrieb:** Die neue Einstellung `TRUSTED_PROXIES` legt fest, von welchem Reverse-Proxy der Server die
  Absenderadresse übernimmt. Wer weitere Container im Netz von Traefik betreibt, sollte sie auf die Adresse des
  Traefik-Containers setzen (siehe Doku „Server“).

Bitte den Server (Image neu bauen und starten) und die Agenten auf den Kinderrechnern auf 0.44.1 aktualisieren.
Details stehen im [Security Advisory](ADVISORY-LINK).
