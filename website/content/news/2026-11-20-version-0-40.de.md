---
title: "Version 0.40: Einladung per Mail"
date: 2026-11-20
version: "0.40.0"
summary: "Betreiber verschicken Einladungscodes direkt per Mail – mit einem Link, der den Code schon einsetzt."
---

Wer KidCTL für mehrere Familien betreibt, kann einen Einladungscode jetzt gleich per Mail verschicken. Die Mail
enthält einen Link, über den die Familie direkt in der Registrierung landet – der Code ist schon eingetragen. Geht
eine Einladung verloren, schickt „Erneut senden“ einen neuen Code. Die Adresse wird gelöscht, sobald der Code
eingelöst oder abgelaufen ist.

Außerdem steht unter der Anmeldung jetzt ein Link zur eigenen Homepage des Betreibers (oder zur KidCTL-Projektseite).
