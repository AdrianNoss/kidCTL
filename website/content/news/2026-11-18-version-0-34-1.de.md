---
title: "Version 0.34.1: Sicherheitsupdate für den Server"
date: 2026-11-18
version: "0.34.1"
summary: "Ein Fehler im Sprachumschalter des Servers ist behoben. Bitte den Server aktualisieren."
---

Version 0.34.1 behebt eine Lücke im Server: Über einen präparierten Link auf die Adresse eures KidCTL-Servers konnte
der Sprachumschalter auf eine fremde Website weiterleiten. Daten waren dabei nicht zugänglich, ein solcher Link
hätte aber für Phishing missbraucht werden können. Betroffen sind die Versionen 0.26.0 bis 0.34.0, die Schwere ist
niedrig.

Bitte den Server auf 0.34.1 aktualisieren (Image neu bauen und starten). Die Agenten auf den Kinderrechnern sind nicht
betroffen. Details stehen im [Security Advisory](https://github.com/AdrianNoss/kidCTL/security/advisories).
