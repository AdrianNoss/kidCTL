---
title: "Version 0.36: More games on Windows"
date: 2026-11-19
version: "0.36.0"
summary: "On Windows, KidCTL now also detects games from the EA app, GOG Galaxy and Battle.net – and games started by a launcher."
---

On Windows, more games now count towards game time and the game limit. New are games from the **EA app**,
**GOG Galaxy** and **Battle.net**, in addition to Steam, Epic and games from the Microsoft Store. If a launcher such as
Ubisoft Connect or Wargaming starts a game, it counts too, even if KidCTL did not know it beforehand.

We also fixed a bug: a game freshly installed through Steam on Windows only counted as a game after several hours.
KidCTL now detects new games within seconds.

The child's Windows computer needs the new version for this. It arrives automatically.
