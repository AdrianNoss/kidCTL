---

With version 0.8, KidCTL is fully usable on Arch Linux with KDE Plasma (Wayland). A server you run yourself, with a
web interface for parents, controls an agent on each child's computer.

- **Screen time:** daily allowance and allowed hours per weekday, warnings, then sign-out with a sign-in lock. This
  also works while the computer is offline.
- **Tray app:** the child sees the remaining time and can ask for more or send a message.
- **App allow list:** only allowed apps run; self-downloaded programs don't.
- **Web filter:** DNS-based, with ready-made bundles such as Wikipedia or YouTube.
- **Updates** come from a signed pacman repository served by your own server.
