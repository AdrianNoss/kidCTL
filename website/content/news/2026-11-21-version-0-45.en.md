---
title: "Version 0.45: Linux connection fixed, invoices with logo"
date: 2026-11-21
version: "0.45.0"
summary: "Linux child computers connect reliably to the server again; new invoices show the logo and name of the service."
---

**Please update the Linux child computers:** With newer versions of the `python-websockets` library (e.g. on Arch
Linux) the agent could no longer connect to a server at `https://`. Rules kept applying with the last known state, but
changes, requests and chat did not get through. 0.45 fixes this. The agent now also disconnects tray app connections
that stop responding right away.

**Chat notifications:** When a computer is newly assigned to a child, the existing chat now appears quietly in the chat
window instead of as a flood of notifications. After the computer was offline, you get a single summary for messages
that came in meanwhile, and decisions on requests made during that time now reliably arrive.

If you run kidCTL with billing, newly issued invoices now show the **logo** and the **name of your service** from
*Administration → Appearance* in the top left corner. Without a logo, only the name is shown. Sender details stay as
before.

Invoices already issued do not change – their PDF stays exactly as it was issued.
